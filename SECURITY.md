# Security policy

This repository is an independent experimental integration. Do not include credentials, private network details, model weights, raw machine logs, or unredacted telemetry in issues or pull requests.

Report suspected vulnerabilities through GitHub private vulnerability reporting when it is available. If it is unavailable, contact the repository owner through a verified private channel instead of opening a public issue.

Security reports should identify the affected revision, impact, reproduction conditions, and a minimally scoped remediation. Do not test against systems or hardware you do not own or have permission to use.
